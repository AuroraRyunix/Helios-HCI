# History

This directory holds point-in-time historical records from Helios-HCI's development: `walkthrough.md` (a chronological log of past bug-hunt/patch rounds), `task.md` (a past task brief), and `readme_old.md` (a superseded project README). They are kept for reference but are not maintained going forward.

For ongoing/open issues, see [docs/audit_findings.md](../audit_findings.md). For the current architecture and usage, see the top-level [README.md](../../README.md).
